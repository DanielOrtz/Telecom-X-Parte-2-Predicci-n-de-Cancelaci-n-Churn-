🤖 Predicción de Cancelación de Clientes – Telecom X (Machine Learning)


Este proyecto forma parte del challenge de ciencia de datos de Alura LATAM dentro del programa Oracle Next Education.

El objetivo es desarrollar modelos de Machine Learning capaces de predecir qué clientes tienen mayor probabilidad de cancelar su servicio (churn) en la empresa ficticia Telecom X.

La predicción del abandono de clientes es un problema común en empresas de telecomunicaciones, ya que permite identificar usuarios en riesgo y aplicar estrategias de retención antes de que decidan cancelar sus servicios.

En este proyecto se construyó un pipeline de Machine Learning que incluye preparación de datos, entrenamiento de modelos de clasificación, evaluación del rendimiento e interpretación de variables clave.

🎯 Objetivos del proyecto

Preparar los datos para su uso en modelos de Machine Learning

Realizar análisis de correlación entre variables

Entrenar distintos modelos de clasificación

Evaluar el rendimiento de los modelos con métricas

Analizar la importancia de variables

Generar insights estratégicos sobre la cancelación de clientes

🧠 Tecnologías utilizadas

El proyecto fue desarrollado utilizando las siguientes herramientas:

Python

Pandas – manipulación y análisis de datos

NumPy – operaciones numéricas

Matplotlib y Seaborn – visualización de datos

Scikit-learn – construcción y evaluación de modelos de Machine Learning

Jupyter Notebook / Google Colab

⚙️ Metodología del proyecto

El proyecto se desarrolló siguiendo un flujo típico de Machine Learning.

1️⃣ Preparación de datos

Se realizó el preprocesamiento del dataset para asegurar su correcta utilización en los modelos.

Entre las tareas realizadas se incluyen:

Limpieza de datos

Tratamiento de valores nulos

Codificación de variables categóricas

Normalización de variables numéricas

División del dataset en datos de entrenamiento y prueba

2️⃣ Análisis de correlación

Se analizaron las relaciones entre variables para identificar aquellas que tienen mayor influencia en la cancelación de clientes.

Este paso permite comprender mejor el comportamiento de los usuarios y seleccionar variables relevantes para el modelado.

3️⃣ Entrenamiento de modelos

Se entrenaron distintos modelos de clasificación para predecir la probabilidad de cancelación de los clientes.

Entre los modelos utilizados se encuentran:

Regresión Logística

Random Forest

Estos algoritmos permiten identificar patrones en los datos y estimar la probabilidad de abandono de cada cliente.

4️⃣ Evaluación de modelos

El rendimiento de los modelos se evaluó utilizando métricas como:

Accuracy

Precision

Recall

F1-score

Matriz de confusión

Estas métricas permiten comparar el desempeño de los modelos y seleccionar el más adecuado.

5️⃣ Interpretación de variables

Se analizó la importancia de las variables dentro del modelo para identificar los factores que influyen en la cancelación de clientes.

Este análisis es clave para transformar los resultados del modelo en insights de negocio.

📊 Resultados principales

El análisis permitió identificar varios factores relacionados con la cancelación de clientes:

Los contratos mensuales presentan mayor tasa de abandono.

Los clientes con menor antigüedad en la empresa tienen mayor probabilidad de cancelar.

Los cargos mensuales elevados se relacionan con una mayor tasa de churn.

Algunos servicios adicionales pueden influir en la fidelización del cliente.

Estos resultados permiten entender mejor el comportamiento de los usuarios y apoyar la toma de decisiones estratégicas.

💡 Conclusión

Los modelos de Machine Learning permiten anticipar la cancelación de clientes mediante el análisis de patrones en los datos.

Gracias a este enfoque predictivo, empresas como Telecom X pueden:

Identificar clientes con alto riesgo de abandono

Diseñar estrategias de retención personalizadas

Mejorar la experiencia del cliente

Reducir la pérdida de ingresos causada por la cancelación de servicios

La aplicación de analítica predictiva representa una herramienta clave para mejorar la toma de decisiones basada en datos.
